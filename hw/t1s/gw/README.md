# T1S gateware: SGMII (10 Mb/s) ↔ 10BASE-T1S

The FPGA on the T1S module sits between the host's SGMII and a LAN867x PHY's MII.

| File | What it does |
|---|---|
| `t1s_bridge.v` | Top level: the whole datapath |
| `sgmii_pcs_phy.v` | SGMII PCS, **PHY side**: comma alignment, 8b/10b, the SGMII config word (announces link / full duplex / 10M, waits for the MAC's ack), `/S/ … /T/ /R/` framing |
| `sgmii_rate10.v` | ×100 byte replication for 10 Mb/s on the 1.25 Gbaud line, sampled mid-copy on receive |
| `frame_fifo.v` | Async frame FIFO: only whole frames are visible to the reader. The reader can rewind (collision → retry) or free a frame, and the writer can abort one |
| `mii_hd_mac.v` | Half-duplex MII MAC for the LAN867x (which does PLCA itself): defer, IFG, fresh preamble, 32-bit jam, binary exponential backoff, drop after 16 attempts |
| `enc8b10b.v`, `dec8b10b.v` | Generated by `gen_8b10b.py` from the IEEE 802.3 Clause 36 tables |

## Tests (Icarus Verilog)

```bash
iverilog -g2012 -o t8 tb/tb_8b10b.v enc8b10b.v dec8b10b.v && vvp -n t8
iverilog -g2012 -o tp tb/tb_pcs.v sgmii_pcs_phy.v enc8b10b.v dec8b10b.v && vvp -n tp
iverilog -g2012 -o tb tb/tb_bridge.v t1s_bridge.v sgmii_pcs_phy.v sgmii_rate10.v \
    frame_fifo.v mii_hd_mac.v enc8b10b.v dec8b10b.v && vvp -n tb     # about 1 minute
```

- **`tb_8b10b`:** 536 vectors against the tables, both directions.
- **`tb_pcs`:** two PCSes back to back, with 3- and 7-bit slips. Checks alignment, AN (the MAC sees `D001`) and a frame each way.
- **`tb_bridge`:** a host (MAC-side PCS + ×100) on one side and a LAN867x-like MII model on the other. Each case must be byte-exact:
  1. A collision on the first attempt; the frame is retried.
  2. T1S → host.
  3. A 40-byte runt is dropped, and nothing reaches the MII side.
  4. 16 collisions, the frame is given up, and the frame queued behind it still goes out whole.
  5. Both directions at once.

  The testbench shortens the backoff slot (`SLOT_SHIFT=2` instead of the standard 7). This runs the same state machine in simulated milliseconds instead of ~180 ms.
