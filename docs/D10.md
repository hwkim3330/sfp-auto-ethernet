# Kontron KSwitch D10 MMT's 2.5G SFP ports

Source: Kontron [AN002 "KSwitch D10 MMT 6G-2GS SFP notes"](https://www.kontron.com/downloads/manuals/k/an002_kswitch_d10_mmt_sfps_v2-0.pdf?product=170637), V2.0, FW GA 2.03, and on this bench the fact that `force10G` on those ports is refused.

## What the port accepts

- **Max 2.5G.** The switch is a LAN9668, and the SerDes behind these two ports does 1G / 2.5G (SGMII, 1000BASE-X, 2500BASE-X). **10G is not possible.**
- **1000BASE-T copper SFPs work with automatic speed.** Tested: Cisco GLC-T, Finisar FCLF-8521-3 / FCLF-8522P2BTL, Methode DM7041-R. They are reported as "1G CuSFP".
- **2.5GBASE-T** (Fiberstore SFP-2.5G-T) works **only with speed 2500 set by hand**. At 1000 there is no link.
- **10GBASE-T SFP+ is not supported**: no link at any setting.
- 1000BASE-X optics work with **speed 1000 FDX set by hand**. 10G optics work at 1000, and only some at 2500.
- AN002 notes that copper SFPs may contain buffers that affect TSN.

## So, for the D10

| Want | Answer |
|---|---|
| 1G RJ45 | **Buy one**: Finisar FCLF-8521-3 (the part AN002 tested) |
| 2.5G RJ45 | **Buy one**: FS SFP-2.5G-T (the part AN002 tested). It has to be fixed at speed 2500 |
| 1 / 2.5 / 10 in one module | **No such option on this port.** 10G-T SFP+ modules get no link; 2.5G-T gets no link at 1G |
| 100/1000BASE-T1 | **Our T1 module** (`hw/t1`), with the firmware built as `make HOST=d10` (below) |
| 2.5/5/10GBASE-T1 | Every such PHY (Marvell 88Q4346 family, Broadcom) is **NDA-only**, so we can't build it. Commercial modules (Technica, Intrepid) exist, but whether their host side works on a 2.5G port is **unverified** |

## Running our T1 module on the D10: `make HOST=d10`

The D10 recognises 1000BASE-T copper SFPs and handles the PHY behind them itself. The modules it was tested with are Finisar/Methode units built on the Marvell 88E1111. **If our module claims 1000BASE-T, the D10 may write Marvell registers into the TI PHY.** So the D10 build:

- sets EEPROM byte 6 to **1000BASE-SX** (0x01). The D10 then treats it as "1G Optical" and does not touch the PHY,
- **turns the PHY's SGMII auto-negotiation off** (SGMII_CTRL_1, MMD1F 0x0608, bit 0). With SGMII AN off, 1G SGMII on the wire is the same as 1000BASE-X without AN,
- **requires the port to be set to speed 1000 full duplex by hand**, exactly as AN002 describes for any 1000BASE-X SFP:

  ```
  (config)# interface 2.5GigabitEthernet 1/1
  (config-if)# speed 1000
  (config-if)# duplex full
  ```

This is design only; **it has not been tested on a real D10.**
